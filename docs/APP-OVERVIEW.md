# SKR Eyes — полное описание приложения

Дата: 19.09.2026. Ветка `design-1.3` (после смелого прохода).
Пакет `dev.alexkosa.skreyes`. В Solana dApp Store: версия 1.2.0 (versionCode 7).
Автор: Alex Kosa (@AlexKosa1), kosa.skr. Бесплатно, открытый код.

## Что это

Глаза для хранилища SKR: приложение показывает всё, что происходит со
стейкингом токена SKR (Seeker, Solana Mobile) — живьём, по финализированным
данным блокчейна, с доказательством у каждой цифры. Плюс личная позиция,
карточка стейкера для X, лидерборд всех людей и честный стейк прямо из
приложения.

Главные принципы, зашитые в код:
- **Каждая цифра с чеком.** Внизу каждого экрана блок Evidence: откуда
  число, какой commitment, когда прочитано. Ничего не выдумывается, тишина
  на чейне = тишина на экране.
- **Приложение не врёт.** Часть стейка, не ушедшая с телефона, называется
  «не ушло с телефона», а не «отклонено чейном». Кнопка, которую нельзя
  нажать, объясняет почему.
- **Ничего о человеке не уходит с телефона.** Нет пуш-сервера, нет
  аналитики; будильники ставит сам телефон.
- **Никогда не уговаривает стейкать.** Ежедневная строка — «я здесь», не
  призыв.

## Архитектура

- **React Native / Expo** (без Expo Go, своя сборка). TypeScript строгий.
- **Свой сервер-индексер** `skr.alexkosa.dev` (VPS): читает чейн своим
  провайдером, отдаёт REST. Приложение ходит только туда и в кошелёк.
- **Сцены** (хранилище, радар) — canvas в WebView: код доказан в браузере,
  данные заходят через `window.__push`, сцена сама ничего не качает.
- **Шрифты**: Geist / Geist Mono (весь интерфейс), Sora (только карточка).
- **Иконка/марка**: глаз с золотой радужкой (Split Lens), рисуется вектором
  в шапке, на карточке и в сцене радара.

### API сервера (всё GET, JSON)

| Ручка | Что отдаёт |
|---|---|
| `/api/state` | Состояние экосистемы: метрики хранилища, очередь выходов, аналитика по окнам 24h/7d/30d, почасовка, guardians, пороги алертов |
| `/api/wallet/<addr>` | Профиль кошелька: позиции, activeStaked, pendingUnstake, withdrawable, earned, nextUnlockAt, имя .skr, provenance |
| `/api/top?list=&offset=&limit=&wallet=` | Лидерборд: stake / earned / movers, по 100 строк, плюс `me` — своя строка |
| `/api/top/find?q=` | Поиск по имени .skr или адресу |
| `/api/events` | Лента финализированных событий (stake/unstake/withdraw) |
| Гейтвей стейка | `blockhash` (перед подписью) и `status` (после), лимит 60 чтений/мин |

## Пять вкладок

### 1. Vault (Хранилище) — главный экран

- **Живая сцена**: дождь телефонов в три глубины; высота кучи = доля SKR в
  стейке; над кучей висят выходы с кольцом 48 часов; подписи только у ходов
  от 1000 SKR. Ночью (21:00–6:00) куча становится городом с горящими
  окнами — доля кошельков, стейкавших сегодня. При первом входе — история:
  куча вырастает с нуля за шесть секунд (один раз).
- Тап по телефону в сцене — **чек**: сумма, кто, подпись, время разблокировки,
  кнопка Solscan.
- **Герой**: активный стейк во весь размер (флип-борд), под ним процент от
  всех SKR.
- **Период**: три числа через волосяные линии — staked / asked out / net — с
  переключателем 24h / 7d / 30d, счётчик кошельков.
- **Очередь выходов** — золотая панель: сколько SKR уходит, сколько позиций,
  «готово к выходу», раскрывашка «когда созреет» (полосы ready/6h/12h/24h/48h),
  список выходов с живым отсчётом (тикают только строки, не весь экран).
- **Motion**: live / calm / off / classic. Classic — старый главный экран 1.0.4
  (флип-борд + тепловая полоса дня), вернули по просьбам людей.

### 2. Flow (Поток) — живой пол хранилища

- Каждая строка — финализированная транзакция. Пыль в 1–2 SKR течёт тонкой
  строкой, крупное — карточками (максимум две открытых, старшие сворачиваются
  в строку-сводку).
- **Headline**: самый крупный ход дня прибит сверху (от 50K SKR), держится
  15 минут.
- Фильтры-чипы: All / Stakes / Exits / Withdrew, на каждом дневной итог.
- **Звук и гаптика на крупные ходы** (от 100K SKR): стейк звонит как старый
  телефон, выход — низкий удар, вывод — закрывающаяся дверь. Тумблеры
  BUZZ / SOUND прямо на экране, не чаще раза в несколько секунд.
- Опрос ленты каждые 6 секунд, только пока вкладка на экране и приложение
  активно.

### 3. Top (Топ) — все, кто стейкает

- Считается **среди людей**: 51 кошелёк размера трежери (4/5 хранилища)
  отложены сервером и названы строкой в подвале — №1 здесь человек.
- **Подиум**: первые трое архитектурой, №1 в золоте с маркой глаза; список
  начинается с №4.
- Три порядка: BY STAKE / BY EARNED / MOVERS·24H (места за сутки, ▲74/▼1/new;
  до первого снапшота честно молчит).
- **Карточка You**: место, ступень (Top 1% и т.д.), стейк, заработок; мини-радар
  как дверь в **полный радар** — WebView-сцена: кольца ступеней, все люди
  точками, ты золотом; pinch-zoom, тап по точке — кто это.
- Поиск по .skr-имени и адресу (локально + сервер, debounce).
- Бесконечная прокрутка по 100; «моя строка» — чип в углу, тап скроллит к себе
  с золотой вспышкой.
- «Share my place» уводит на Me и сразу открывает шаринг карточки.

### 4. Me (Моя позиция)

- **Карточка стейкера** — фото-объект (сгенерированный металл с порталом),
  поверх — гравировка: имя (.skr / метка кошелька / адрес), дни в стейке
  (точно или ≥, из первой подписи позиции), «One of N positions», место среди
  людей, позиция в SKR. В кольце — глаз: **при скрытом имени глаз
  закрывается**. Та же картинка и на экране, и в экспорте — один рисунок,
  никогда не расходятся.
- **Стейк** — синяя кнопка-герой сразу под карточкой. **The daily sixteen** —
  золотая строка: 16 SKR · 16 транзакций · ≈6 подтверждений.
- **Панель позиции**: вес в хранилище (%, золотая шкала), место (тап — своя
  строка в Топе), заработано (+SKR, пояснение за раскрывашкой), очередь:
  Leaving / Ready-Next unlock утопленными ячейками.
- **Приватность карточки** за раскрывашкой «What the card shows»: скрыть имя /
  скрыть сумму / показывать место. Честные предупреждения о связках («сумма
  рядом с датой — почти отпечаток»; при скрытом имени карточка показывает
  только ступень, чтобы место не привело к твоей строке в Топе).
- **Share your card**: PNG 1600×900 (как X показывает в ленте), фон-комната,
  отражение, подпись-кэпшн в буфер. Карточка запоминается на диске — холодный
  старт никогда не показывает дыру.
- Подключение: Mobile Wallet Adapter (read-only) **или** просто вставить любой
  адрес (смотрим, не подписываем). Disconnect стирает всё: сессию, карточку,
  сохранённый прогон стейка, будильники.
- Тихие ссылки: Wake me at unlock / Disconnect / кнопка-стрелка обновления.
  Автоперечитка каждую минуту и при возврате в приложение.

### 5. Alerts (+ настройки)

- **Разбудить на разблокировке**: телефон сам ставит будильники на точное
  ончейн-время (за час и в момент). Никакого сервера.
- **Крупные ходы со звуком** (порог 100K, пороги приходят с сервера и видны
  в таблице «What counts as large»).
- **Ежедневный взгляд**: раз в день около шести вечера одна строка о
  хранилище, семь вариантов по дням недели, никогда не зовёт стейкать.
- Выбор **заставки** (Turn / First stone) и **языка** (11 языков, каждый
  написан своим письмом). Пояснения свёрнуты за имена настроек.
- Тест-уведомление. Внизу — золотая панель Support SKR Eyes → лист доната.

## Стейк (главная механика)

- Программа: `SKRskrmtL83pcL4YqLWt6iPefDqwXQWHSw9S9vz94BZ`, минт
  `SKRbvo6Gf7GondiT3BbTfuRDPqLWei4j2Qy2NPGZhW3`, decimals 6, минимум 1 SKR
  на транзакцию, до 16 частей, guardian pool по умолчанию зашит.
- Приложение **само строит** транзакции (stake-инструкция + ATA idempotent),
  кошелёк подписывает и рассылает пачкой в одно одобрение
  (`signAndSendTransactions`); подписи записываются на диск **до** всего
  остального — сохранённая подпись переспрашивается, никогда не заменяется.
- Экран: быстрые суммы 1/5/10/всё; у каждой разбивки цена в касаниях пальцем
  (Seed Vault ≈3 транзакции на отпечаток), от 8 частей — золотым; проверка
  баланса до подписи; итог крупным синим.
- **Прогон**: сетка ячеек по одной на часть + леджер вердиктов. Состояния:
  pending / sent / confirmed / failed (чейн сказал нет) / **unsent (не ушло с
  телефона)** / unknown (чейн молчит, подпись сохранена). Опрос статусов по
  кругу, не быстрее 60/мин, три минуты потолок; возврат из фона возобновляет
  опрос. Прерванный прогон переживает перезапуск приложения.
- Первый стейк создаёт позицию (рента ~0.00207 SOL, честно показана).
- «Шестнадцать» — пресет 16×1 SKR из Me.

## Донат (новое, 19.09)

Лист «Send a thank you»: **любая монета**. SOL по умолчанию (есть у всех),
SKR и USDC рядом, «любая монета» — голый адрес. Сумма огромной цифрой,
быстрые пресеты, золотая кнопка. Работает через **ссылку Solana Pay**
(`solana:<адрес>?amount=&spl-token=`) — кошелёк открывается с заполненными
полями и сам строит/подписывает/шлёт. Наш домен в сделке не участвует, то
есть донат живёт даже под блокировкой кошелька. Рядом QR — можно отсканировать
любым другим телефоном. Получатель: kosa.skr
(`BmJaEmaEURBDpj91GUTvJcpKy2MAu8ZtRFRPaMpEuuax`); чаевые в SKR сразу целиком
идут в стейк.

## Заставки

- **Turn** (по умолчанию): телефон-силуэт поворачивается, глаз выходит из
  камеры и моргает; сзади кольца радара и луч, один оборот. Звук — фирменный
  свип с эхом (эхо родилось из бага, оставлено нарочно).
- **First stone**: один телефон падает в темноту, звон, волна поднимает
  тысячи держателей, глаз открывается и подмигивает.
- Обе пропускаются тапом. Обе уважают выключенный звук и buzz.

## Звук и гаптика

Восемь голосов (flip, surge, stake, drop, tudum, coin, door, ring), у каждого
своя вибрация. Всё уважает системный reduced motion и тумблеры.

## Языки

11: en, de, zh, ru, es, pt, tr, vi, id, ko, ja. Ключ = английская фраза из
кода; `npm run i18n:check` держит таблицы в нуле сирот. Карточка для X всегда
на английском (чтобы читалась одинаково у всех).

## Дизайн-система (1.3)

Тёмный OLED (#04070B), «свет вместо рамок»: панели подсвечены кромкой, не
обведены; Inset — утопленные строки; один акцент (циан #56E0FF), один металл
(#C9A96A — тратится только на своё: карта, очередь, подиум, донат), три
цвета состояний. Ничего читаемого мельче 11px. Табличные цифры везде, где
числа меняются. Пять нарисованных иконок вкладок, живая — в лужице света.

## Известные ограничения (на 19.09)

- Штатный кошелёк Seeker блокирует транзакции с нашим доменом («Scam site
  detected») — переписка с Solana Mobile идёт; донат через Solana Pay блока
  не касается.
- Кошелёк просит подключение каждый раз (нужен reauthorize) — в работе.
- Отклонённые части нельзя дослать отдельно (только Ask again / Start over).
- Blockhash берётся до окна кошелька и может состариться за время
  подтверждения.
- ≈6 подтверждений на 16 частей — оценка, ждёт замера на телефоне.
