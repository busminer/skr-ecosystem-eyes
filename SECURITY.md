# Security policy

## Supported version

The latest commit on the default branch is the supported community beta.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting or a private security advisory for security-sensitive findings. Do not publish credentials, exploit details, private RPC URLs, or user data in a public issue.

This project is read-only by design. A change that introduces wallet connection, signing, transaction submission, custody, or secret-bearing API responses must be treated as a security-sensitive architectural change.
